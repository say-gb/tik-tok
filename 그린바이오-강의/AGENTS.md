# AGENTS.md — 그린바이오-강의 (그린바이오 전자상거래개론 강의자료 제작)

루트 `AGENTS.md`(협업 규약)와 `낭만클럽-세팅/CLAUDE.md`(말투·검증)는 **그대로 적용**된다.
이 파일은 그 위에 **이 폴더 작업에만 붙는 규칙**을 더한다. 어긋나면 루트 규약이 이긴다.

## 0. 이 과목의 정체성 — 가장 먼저 지킬 것

**이 과목은 "그린바이오 전자상거래"다.** (호서대 2026-2, 담당 최경집 교수, 온라인 녹화강의)

- 모든 자료·사례·데이터는 **전자상거래(온라인) 관점 중심**으로 만든다.
- 기초 이론 주차도 오프라인 설명에서 끝내지 않고 **"온라인에서는 어떻게 바뀌는가"** 로 연결한다.
- 오프라인 사례는 비교용으로만 쓰고, 결론은 온라인으로 맺는다.
- 슬라이드마다 "온라인 판매·플랫폼·디지털과 연결되는가?"를 점검한다. (6주차 초안이 오프라인 위주라 전면 개편한 전례가 있다.)

## 1. 폴더 구조

```
그린바이오-강의/
├── AGENTS.md        ← 이 파일 (Codex가 자동으로 읽음)
├── CLAUDE.md        ← Claude Code용, AGENTS.md를 불러옴
├── syllabus.md      ← 강의계획서 원본 (교수님 제공)
├── template.pptx    ← 5주차 1차시 교수님 완성본에서 사진·음성만 뺀 템플릿. ⛔ 수정 금지
├── engine.py        ← 생성 엔진 (슬롯 위치표 SLOTS, build/qa/script_docx)
├── build.py         ← 실행기: python build.py specs/09-1.json
├── specs/           ← 차시 하나 = JSON 하나 (문구 + 대본). 06·07주차 6개가 실제 예시
└── output/          ← 빌드 결과 (PPT + 미니맥스 대본 docx)
```

## 2. 역할 분담 (루트 규약 1번의 이 폴더 버전)

| 단계 | 담당 | 내용 |
|---|---|---|
| ① 리서치·검증 | Claude Code | 웹 검색으로 수치·사례 확인, 출처 정리 |
| ② spec 작성 | Claude Code | `specs/NN-c.json`에 슬라이드 문구 103칸 + 대본 11개 |
| ③ 빌드·QA | Codex | `python build.py specs/NN-c.json` 실행, 기준 미달이면 Claude에 되돌림 |
| ④ 엔진 수정·대량 처리 | Codex | `engine.py`, `build.py` |
| ⑤ 최종 확인 | 교수님 | 파워포인트에서 넘겨 보며 글자 겹침 확인, 사진·음성 삽입 |

- 웹 검색이 되는 쪽이 ①②를 맡는다. Codex는 기본 샌드박스에서 네트워크가 막히므로 **수치를 지어내지 말고** 필요한 숫자를 `.agents/작업일지.md`에 `- [ ] (claude) …` 로 남긴다.
- 넘길 때는 루트 규약대로 `.agents/작업일지.md`에 한 줄. 잡고 있는 spec 파일 경로도 적는다.

## 4. spec 형식 (`specs/NN-c.json`)

```json
{
 "week": 9, "cha": 1,
 "topic": "글로벌 유통 동향",
 "file_title": "글로벌_유통_동향",
 "slide_titles": ["타이틀 — 글로벌 유통 동향", "이번 주 로드맵", "섹션 1 — …", "…", "…", "…", "섹션 2 — …", "…", "…", "생각해보기", "1차시 핵심 정리"],
 "content": { "S1.week": "W E E K  9   ·   1 차 시", "S1.title1": "글로벌 전자상거래", "...": "..." },
 "notes": ["1장 대본", "...", "11장 대본"]
}
```

- `content`는 아래 슬롯표의 **103칸을 전부** 채운다. 빠지면 템플릿(5주차) 원문이 남고 build가 ⚠로 알려 준다.
- `notes`는 정확히 11개. 슬라이드 노트와 대본 docx에 같은 글이 들어간다.
- 새 주차는 **`specs/07-2.json`을 복사해서 시작**하는 게 가장 빠르고 안전하다.
- 2장(로드맵)은 세 차시 spec에 **같은 문구**를 넣는다. 강조 테두리는 `cha` 값에 맞춰 엔진이 자동으로 옮긴다.

### 슬롯표 — 괄호 안은 최대 글자수 (넘으면 화면에서 겹친다)

| 장 | 역할 | 슬롯 |
|:--:|---|---|
| 1 | 타이틀 | `week`("W E E K  9   ·   1 차 시") / `title1` 대주제(14) / `title2` 차시주제(**14 — 넘으면 3줄이 되어 태그라인과 겹침**) / `tagline`(20) / `photo` "권장 — ○○ (세로형)" |
| 2 | 로드맵 | `subtitle`(35) / `c1~c3_title`(12) / `c1~c3_l1`, `_l2`(14) / `bottom` 연결 문장(45) |
| 3 | 섹션 1 | `photo` / `title1`(9) / `title2`(9) / `sub1`(16) / `sub2`(16) |
| 4 | 개념 4행 | `label`(영문 대문자 띄어쓰기 "D E F I N I T I O N") / `title`(18) / `subtitle`(35) / `r1~r4_h`(32) / `r1~r4_d`(22) |
| 5 | 데이터 | `label`("D A T A") / `title`(18) / `subtitle`(35) / `a_`·`b_` `period`(10) `value`(10) `label`(18) `d1` `d2`(18) / `source` 출처(70) |
| 6 | 4카드 | `label` / `title`(18) / `subtitle`(35) / `k1~k4_title`(8) / `k1~k4_l1`, `_l2`(10) / `bottom`(45) |
| 7 | 섹션 2 | 3장과 같음 |
| 8 | 특징 4행 | 4장과 같음 |
| 9 | 적용·사례 4행 | 4장과 같음 |
| 10 | 생각해보기 | `title1`(12) / `title2`(12) / `body1`(55) / `body2`(55) |
| 11 | 핵심정리 | `title` "n차시 핵심 정리" / `subtitle` / `r1~r3_h`(35) / `r1~r3_d`(22) / `next_label` "다음 차시"·"다음 주" / `next_title`(18) |

- 사진은 넣지 않는다. 교수님이 직접 넣는다. `photo` 칸에 권장 사진만 적는다.

## 5. 대본(notes) 규칙 — 미니맥스 TTS

- **차시당 25분 이상**: 449자 ≈ 1분(5주차 미니맥스 실측) → 차시당 **11,300~11,700자**, 장당 평균 약 1,050자.
- **대본 속 아라비아 숫자 0개.** 숫자·연도·퍼센트·영문 약어는 한글로 풀어 쓴다.
  - 2025년 → 이천이십오년 / 49.2% → 사십구 점 이 퍼센트 / 1조 2,365억 원 → 일조 이천삼백육십오억 원
  - 11.1%p → 십일 점 일 퍼센트포인트 / 3주차 → 삼 주차 / 1차시 → 일 차시 / 249개 → 이백사십구 개
  - D2C → 디투씨 / B2B → 비투비 / SNS → 에스엔에스 / AI → 에이아이 / IoT → 아이오티
- 슬라이드 화면 글자(`content`)는 숫자 그대로 쓴다.
- 1장: 지난 차시 요약 → 오늘의 질문 → 학습목표 3개. 11장: 핵심 3가지 → 다음 차시 예고 → "수고하셨습니다."
- 4·8·9장: "첫째… 둘째…"로 4행을 순서대로, 항목마다 예시 하나. 5장: 숫자의 의미 → 이유 → 그린바이오에 주는 의미 → 출처.
- 앞 주차 연결 멘트 필수("사 주차의 콜드체인", "일 주차의 디투씨").
- 분량을 채울 때 같은 말을 되풀이하지 않는다. 예시·주차 연결·실무 팁을 더한다.

## 6. 검증 규칙

- 모든 수치·사례는 검색으로 확인한 뒤 쓰고 5장 `source`에 기관·매체·연월을 적는다.
- 업계 추산은 대본에 "추산", 계산 예시는 "예시"라고 밝힌다. 확인 못 한 것은 쓰지 않거나 `[미검증]`.
- 기업 실패 사례는 비난이 아니라 교훈 중심.

## 7. 알려진 함정 (실제로 겪은 것)

1. **음성 자동재생 설정(`p:timing`)이 남으면 파워포인트가 파일을 못 연다.** 엔진이 지우지만, 다른 템플릿을 쓰면 다시 확인할 것.
2. 로드맵 강조 테두리가 1차시 카드에 고정되던 문제 → 엔진이 `cha`로 자동 이동.
3. 표지 `title2`가 길면 3줄이 되어 태그라인과 겹친다(7주차 2차시에서 발생).
4. 이 환경에는 PPT를 이미지로 렌더링해 볼 도구가 확실하지 않다 **[미검증]**. 글자수 한도를 지키고, 최종 확인은 교수님 파워포인트로.
5. `template.pptx`를 열어서 저장만 해도 도형 순서가 바뀔 수 있다. **수정 금지.** 템플릿을 바꿔야 하면 `engine.py`의 `SLOTS`를 다시 측정해야 한다.
