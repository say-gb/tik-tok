# 코덱스 + 클로드코드 같이 쓰기 (5분)

**결론부터.** 두 놈을 "연결"하는 스위치는 없습니다.
같은 폴더(= 같은 GitHub 리포)를 열고, **규칙 파일 하나를 공유**하게 만들면 그게 연결입니다.
이 리포는 방금 그렇게 세팅됐습니다.

```
tik-tok/
├── AGENTS.md              ← 코덱스가 읽는 규약 (공통 원본)
├── CLAUDE.md              ← 클로드가 읽음. 내용은 AGENTS.md를 불러옴
├── .agents/
│   ├── 작업일지.md         ← 둘 사이 인수인계 창구
│   └── skills-sync.py     ← 스킬을 코덱스용으로 복제
├── .codex/skills/         ← 코덱스용 스킬 포인터 (자동 생성)
└── 낭만클럽-세팅/
    ├── CLAUDE.md          ← 말투·정체성 원본 (여기만 고치면 양쪽에 적용)
    ├── AGENTS.md          ← 이 폴더 안내
    └── .claude/skills/    ← 스킬 원본 6종
```

규칙을 고칠 땐 **`AGENTS.md`와 `낭만클럽-세팅/CLAUDE.md` 두 개만** 고치세요. 나머지는 따라옵니다.

---

## 1. 코덱스 깔기

터미널(윈도우는 PowerShell) 열고 한 줄.

```
npm install -g @openai/codex
```

Node가 없으면 먼저 [nodejs.org](https://nodejs.org) 에서 LTS 받으시면 됩니다.

설치 확인:

```
codex --version
```

> 설치 스크립트 방식(`curl -fsSL https://chatgpt.com/codex/install.sh | sh`)도 있습니다. **[미검증]** — npm 방식이 제일 안 꼬입니다.

## 2. 로그인

폴더로 들어가서 그냥 실행하면 로그인 안내가 뜹니다.

```
cd <낭만클럽 리포 폴더>
codex
```

ChatGPT 계정으로 로그인합니다. **[미검증]** 유료 플랜(Plus/Pro) 또는 API 키가 필요합니다 — 화면 안내를 따르세요.

## 3. 되는지 확인 (이게 핵심 테스트)

코덱스 안에서 이렇게 물어보세요.

```
AGENTS.md 읽고, 나를 뭐라고 불러야 하는지랑 스레드 글 쓸 때 먼저 읽어야 하는 파일 말해봐
```

→ **"교수님"** + `낭만클럽-세팅/.claude/skills/스레드/SKILL.md` 가 나오면 붙은 겁니다.

안 나오면 폴더를 잘못 열었습니다. `AGENTS.md`가 보이는 위치에서 `codex`를 실행해야 합니다.

---

## 4. 둘을 같이 일 시키는 세 가지 방법

### ① 릴레이 — 제일 많이 쓰실 패턴

클로드로 원고를 쓰고, 코덱스한테 렌더링·자동화를 넘깁니다.

```
[클로드] /브런치 다음 화 초안 써줘  → 커밋 → 푸시
[코덱스] 작업일지 읽고, 방금 올라온 원고로 카드뉴스 7장 렌더해줘
```

넘기는 방식은 **말이 아니라 `.agents/작업일지.md`** 입니다. 앞사람이 한 줄 남기고, 뒷사람이 그걸 읽고 시작합니다. 교수님은 "작업일지 남겨줘" 한마디만 하시면 됩니다.

### ② 분업 — 동시에

창 두 개 띄워서 같이 돌립니다. 단, **같은 파일은 절대 동시에 안 만집니다.**

```
[클로드] 브랜치 claude/브런치-2화   → 원고
[코덱스] 브랜치 codex/렌더-개선     → render.py
```

작업일지의 `## 지금 잡고 있는 파일`에 각자 경로를 적으니 서로 피해 갑니다.

### ③ 교차 검수 — 품질이 필요할 때

한쪽이 쓰고 다른 쪽이 깝니다.

```
[코덱스] 낭만클럽-세팅/CLAUDE.md 기준으로 이 원고 톤 위반 찾아내. 고치진 말고 지적만.
```

자기 글은 자기가 잘 못 봅니다. 이게 의외로 잘 먹힙니다.

---

## 5. 스킬 고쳤을 때

`낭만클럽-세팅/.claude/skills/` 안의 `SKILL.md`를 고치셨으면, 한 줄 돌려주세요.

```
python .agents/skills-sync.py
```

코덱스용 포인터(`.codex/skills/`)가 다시 맞춰집니다. 안 돌려도 코덱스는 `AGENTS.md`의 라우팅 표를 보고 원본을 찾아가니 치명적이진 않습니다.

## 6. 충돌 났을 때

`git pull` 하다가 충돌(conflict)이 나면 혼자 풀지 마시고 **클로드에게 "충돌 정리해줘"** 하시면 됩니다.
애초에 안 나게 하려면 규칙 하나만 지키면 됩니다 — **작업 시작 전에 `git pull`, 끝나면 바로 `git push`.**

## 7. GitHub에서 자동으로 쓰기 (선택)

지금 이 리포에는 클로드 워크플로우 4개가 돌고 있습니다(`daily-threads`, `brunch-draft`, `column-draft`, `claude`).
코덱스도 GitHub에 붙일 수 있습니다. **[미검증]** — ChatGPT 쪽에서 Codex용 GitHub 앱을 설치하고 리포 접근을 허용하는 절차가 필요합니다. 이건 나중에 필요해지면 붙이시는 걸 권합니다. 지금은 로컬에서 두 놈 같이 쓰는 것만으로 충분합니다.

## 한 장 요약

| 할 일 | 명령 |
|---|---|
| 코덱스 설치 | `npm install -g @openai/codex` |
| 코덱스 실행 | 리포 폴더에서 `codex` |
| 클로드 실행 | 클로드 앱 → Code → 같은 폴더 |
| 규칙 고치기 | `AGENTS.md` 또는 `낭만클럽-세팅/CLAUDE.md` |
| 스킬 고친 뒤 | `python .agents/skills-sync.py` |
| 인수인계 | `.agents/작업일지.md` 한 줄 |
