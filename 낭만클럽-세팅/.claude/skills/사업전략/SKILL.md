# 사업 전략 문서

## 고정 구조 (예외 없음)

### 1. 문제 인식
- 지금 무엇이 안 되고 있는가. **숫자로.**
- 왜 지금인가. 타이밍 근거.
- 남들은 왜 못 풀었는가.

### 2. 전략 방향
- 한 문장으로 요약되는 방향. 길면 전략이 아니라 소망이다.
- 버리는 것도 명시한다. 안 하는 걸 정해야 전략이다.

### 3. 실행 방안
| 단계 | 무엇을 | 언제까지 | 누가 | 돈 |
|---|---|---|---|---|

- 3개월 안에 시작할 수 있는 것만 1단계에 넣는다.
- "검토한다", "추진한다" 같은 동사 금지. 검증 가능한 동사만.

### 4. 기대 효과
- 정량: 매출·마진·건수. 산출 근거를 반드시 붙인다.
- 정성: 2개 이하.
- **리스크 3개와 대응책**을 같이 쓴다. 이게 빠지면 제안서가 가벼워 보인다.

## 숫자 규칙

- 시장 규모, 경쟁사, 단가, 제도는 **검색해서 확인**한다.
- 확인 못 한 숫자는 `[추정]`을 붙이고 산출 로직을 노출한다.
- 근거 없는 "시장 규모 O조원"은 쓰지 않는다. 제안서 신뢰가 여기서 무너진다.

## 교수님 관심 영역 (맥락으로 활용)

B2B 식자재·유통·풀필먼트 / 공동구매몰 / 신선식품 / 김치·떡볶이 /
그린바이오 / 평생교육·강의 사업

## 문서 톤

제안서는 낭만클럽 톤을 **절반만** 쓴다.
- 유지: 결론 먼저, 짧은 문장, 구체적인 숫자, 텅 빈 수식어 금지.
- 자제: 위트, 감성 장면. 단 **표지 카피와 첫 문장은 후킹 있게.**

## 출력

바로 인쇄해서 들고 갈 수 있는 완성본으로 준다.
분량이 길면 먼저 목차 + 각 장 핵심 한 줄을 보여주고 교수님 확인 후 본문으로 간다.
