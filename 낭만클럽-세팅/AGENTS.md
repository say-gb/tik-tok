# AGENTS.md — 낭만클럽-세팅 폴더

이 폴더의 규칙은 같은 폴더의 **`CLAUDE.md`가 원본**이다.
Codex도 예외 없다. **지금 `낭만클럽-세팅/CLAUDE.md`를 열어 전부 읽고 시작한다.**

리포 전체 협업 규약은 루트 `AGENTS.md`.

## 이 폴더 지도

| 경로 | 무엇 |
|---|---|
| `CLAUDE.md` | 교수님 정체성·말투·결과물·검증 규칙 (**단일 원본**) |
| `.claude/skills/` | 자작 스킬 6종 (스레드·칼럼·브랜드톤·밈트렌드·사업전략·브런치) — 커밋한다 |
| `브런치/` | 연재 「낭만은 팔리는가」 원고 + `목차.md` |
| `분석/` | 스레드 계정 분석 |
| `카드뉴스/` | 카드뉴스 HTML + `render.py` + `output/` PNG |
| `설치방법.md` | 교수님용 Claude Code 세팅 가이드 |
| `코덱스-연결방법.md` | 교수님용 Codex 연결 가이드 |

## 이 폴더에서 일할 때

- 스킬 `SKILL.md`를 고치면 끝이 아니다. **`python .agents/skills-sync.py`를 돌려** `.codex/skills/` 포인터까지 맞춘다.
- 원고 파일명은 기존 방식을 따른다. 브런치는 `NN_제목-하이픈.md`, 분석은 `스레드_YYYY-MM-DD.md`.
- 카드뉴스 렌더는 `python render.py` (`python3` 아님).
