# 낭만클럽 세팅 — 설치 방법 (3분)

## 1. 폴더 만들기

바탕화면에 폴더 하나 만드세요. 이름은 `낭만클럽` 정도로.

## 2. 파일 넣기

압축 푼 안에 있는 이 두 개를 **통째로** 그 폴더에 넣습니다.

```
낭만클럽/
├── CLAUDE.md          ← 교수님 소개 + 말투 규칙
└── .claude/
    └── skills/
        ├── 브랜드톤/SKILL.md
        ├── 스레드/SKILL.md
        ├── 칼럼/SKILL.md
        ├── 밈트렌드/SKILL.md
        └── 사업전략/SKILL.md
```

> `.claude` 폴더가 안 보이면 숨김 폴더라서 그렇습니다.
> 윈도우 탐색기 → 보기 → **숨긴 항목** 체크하면 나옵니다.

## 3. 클로드 앱에서 열기

1. 클로드 앱 → **Code 탭**
2. **Local** → **Select folder** → 방금 만든 `낭만클럽` 폴더 선택
3. 모델은 **Opus** 로 두시면 됩니다

## 4. 되는지 확인

입력창에 이렇게 쳐보세요.

```
/memory
```
→ CLAUDE.md 내용이 뜨면 성공입니다.

```
/스레드 김치 소비가 줄어드는 진짜 이유
```
→ 스레드 글 3개가 나오면 스킬도 붙은 겁니다.

---

## 명령어 5개

| 명령 | 하는 일 |
|---|---|
| `/브랜드톤 [내용]` | 낭만클럽 톤으로 쓰거나, 기존 글 톤 고치기 |
| `/스레드 [주제]` | Threads·인스타 글 3개 (각도별) |
| `/칼럼 [주제]` | 제목 5개 → 고르면 본문 |
| `/밈트렌드 [키워드]` | 요즘 밈·트렌드 검색 + 써먹을 각도 |
| `/사업전략 [아이템]` | 문제인식 → 전략 → 실행 → 기대효과 |

명령어 없이 그냥 "요즘 떡볶이 밈 뭐 있어?" 라고 물어도 클로드가 알아서 스킬을 꺼내 씁니다.
